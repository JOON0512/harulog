# 하루로그

친구 몇 명과 오늘의 할 일을 기록하는 작은 웹 앱입니다.

## 사용할 수 있는 기능

- ChatGPT 계정 로그인 / 로그아웃, 닉네임 설정
- 날짜별 할 일 작성, 수정, 완료, 삭제
- 집중 / 일상 / 기타 분류
- 각 할 일의 **나만 보기 / 친구에게 공개** 설정
- 친구 코드로 요청, 상대방의 수락, 요청 취소와 친구 연결 해제
- 수락한 친구들이 선택한 날짜에 공개한 할 일 보기
- 휴대폰과 컴퓨터에 맞춘 화면

로그인 전 보이는 할 일은 **사용 예시**입니다. 실제 계정에는 예시 데이터가 저장되지 않습니다. 실제 기록은 서버 데이터베이스에 저장됩니다.

## 로그인과 친구 초대

이 첫 버전은 **ChatGPT 계정 로그인**을 사용합니다. 일반 이메일·비밀번호 회원가입은 구현하지 않았습니다. Sites의 방문자 접근 권한과 앱 안의 친구 관계는 별개입니다. 초대받은 방문자는 Sites 접근 권한도 있어야 접속할 수 있습니다. 모든 사용자에게 사이트를 열어 두는 설정을 쓰더라도, 앱 안에서 서로 요청을 수락한 친구만 공개 기록을 조회할 수 있습니다.

1. 사이트에 접속하고 ChatGPT 계정으로 로그인합니다.
2. 친구들에게 보일 닉네임을 저장합니다.
3. ‘친구 추가’에서 자기 코드를 친구에게 전달합니다.
4. 한 사람이 상대 코드를 입력해 요청을 보내면, 상대방은 ‘친구들의 하루’에서 수락합니다.
5. 공개 범위를 ‘친구에게 공개’로 지정한 할 일만 상대에게 보입니다. 기본값은 ‘나만 보기’입니다.

다른 사람의 비공개 기록은 API 응답에 포함되지 않습니다. 사용자의 신원은 호스팅 플랫폼이 검증한 헤더에서 얻으며, 브라우저가 보낸 사용자 ID를 신뢰하지 않습니다. 실제 서비스는 Sites의 인증 프록시 뒤에 배포해야 합니다.

## 코드를 읽는 순서

- `app/page.tsx`: 로그인 여부를 확인하고 화면을 엽니다.
- `app/harulog.tsx`: 달력, 할 일, 친구 화면과 버튼 동작입니다.
- `app/globals.css`: 색상, 글꼴, 간격, 모바일 배치입니다.
- `app/api/[resource]/route.ts`: 로그인과 권한을 확인한 후 저장 / 수정 / 삭제합니다.
- `lib/store.ts`: 내 기록과 친구에게 공개된 기록만 조회합니다.
- `db/schema.ts`: 프로필, 할 일, 친구 관계의 저장 구조입니다.
- `drizzle/`: 배포할 때 적용되는 데이터베이스 구조 변경 기록입니다.

HTML·CSS·JavaScript를 바탕으로 React와 TypeScript를 사용합니다. TypeScript는 JavaScript 값의 형태를 미리 확인해 주는 도구입니다. 데이터베이스는 Sites가 제공하는 Cloudflare D1(SQLite)입니다.

## 로컬 실행

Node.js 22.13 이상이 필요합니다. 이 작업 환경에서는 Node 24로 검증했습니다.

```sh
npm ci
npm run build
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_milky_sauron.sql
npm run dev
```

데이터베이스 초기화 명령은 새 로컬 데이터베이스에 한 번만 실행합니다. 미리보기 주소는 실행 결과에 표시됩니다. 로컬의 ‘ChatGPT로 로그인’은 개발 전용 가상 계정으로 연결됩니다. 이 기능은 배포 빌드에 포함되지 않습니다. 로컬에 작성한 데이터는 서비스에 업로드되지 않습니다.

```sh
npx tsc --noEmit
node tests/api-security.mjs
```

보안 통합 테스트는 `HARULOG_TEST_URL`로 지정한 로컬 빌드 미리보기에서만 실행합니다. 실제 배포 주소에 테스트 데이터를 만들지 않습니다. 자세한 실행 조건은 테스트 파일 상단을 참고하세요.

배포 구성은 `.openai/hosting.json`에 있습니다. 비밀번호와 서비스 토큰을 코드 또는 Git에 넣지 마세요.

공개 저장소의 `project_id`는 예시 값입니다. 자신의 Sites 프로젝트에 배포할 때 교체하세요.
기존 서비스의 데이터베이스나 사용자 기록은 이 저장소에 포함하지 않습니다.

2026-10-24 공개 준비 과정에서 TypeScript 검사와 로컬 프로덕션 빌드를 다시 통과했습니다.
원래 구현의 API 권한 통합 테스트는 `tests/api-security.mjs`에 보존했습니다.
